Guia MAnipulacion Y Manejo De La Herramienta Git

Git es una herramienta que permite guardar los cambios realizados en un proyecto y llevar un registro de su evolución. Es muy útil para programadores, ya que facilita el control de los archivos y permite recuperar versiones anteriores si ocurre algún error. Además, ayuda a trabajar en equipo sin perder el progreso realizado

Para subir un archivo utilizando Git, primero se debe abrir la terminal en la carpeta del proyecto. Luego, se utiliza el comando git add nombre_del_archivo para seleccionar el archivo que se desea guardar. Después, se ejecuta git commit -m "Descripción del cambio" para registrar el cambio y, finalmente, git push para subirlo al repositorio remoto, como GitHub

Imaginemos que creamos un archivo llamado index.html para una página web. Primero, escribimos git add index.html para seleccionar el archivo; luego, git commit -m "Agregué la página principal" para guardar el registro del cambio, y finalmente, git push para enviar los cambios a GitHub. De esta manera, el archivo queda disponible en el repositorio remoto, siempre que la conexión y la configuración estén preparadas

En conclusión, Git facilita la organización y el seguimiento de los proyectos mediante un proceso sencillo para registrar y compartir archivos. Al comprender comandos básicos como git add, git commit y git push, es posible comenzar a utilizar esta herramienta sin necesidad de conocer funciones avanzadas. Con la práctica, Git se convierte en un apoyo importante para desarrollar proyectos de forma ordenada y segura

1.DOCTYPE: Indica que el documento utiliza HTML5 , la versión moderna de HTML

2.HTML: Es la etiqueta principal que contiene todo el contenido de la página web

3.HEAT: Contiene información sobre la página, como sus metadatos ,el título y los enlaces a archivos CSS

4.META: Proporciona información adicional sobre el documento, como la codificación de caracteres o la configuración para dispositivos móviles

5.TITLE: Define el título que aparece en la pestaña del navegador

6.BODY: Contiene todo el contenido visible de la página web , como textos, imágenes, botones y enlaces

7.H1: Se utiliza para crear el encabezado principal de una página o sección . Es uno de los títulos más importantes del documento.

8.P: Permite escribir párrafos de texto para organizar y presentar información de manera clara
